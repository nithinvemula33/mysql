-------------------------SQL(Structured Query Language)-----------------------------

**DATABASE**

A database is an organised collection of data which is stored and accessed electronically.
The data structured in way that allows easy retrival ,management and updating.
Databases are essential for handling large amounts of imformation in a structured and efficient manner.

**DBMS(DATABASE MANAGEMENT SYSTEM)**

A DBMS is software that allows user to define,create,maintain and control access to database.
It acts as an intermediary between user and database, ensuring that the data is stored efficiently,retrived quickly and managed securly.

//Main Categories of SQL Commands

# DDL (Data Definition Language)

Purpose: Defines database structure.
Commands: CREATE, ALTER, DROP, TRUNCATE.

# DML (Data Manipulation Language)

Purpose: Modifies data.
Commands: INSERT, UPDATE, DELETE.

# DQL (Data Query Language)

Purpose: Used to retrieve data from a database.
Commands: SELECT.

# DCL (Data Control Language)

Purpose: Used to control access and permissions in a database.
Commands: GRANT,REVOKE.
